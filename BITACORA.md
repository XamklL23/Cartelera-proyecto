# Bitácora: Cartelera de Películas

Proyecto de aprendizaje en React que consume la API de TMDB.
Aquí documento cada avance: qué hice y para qué sirve.

## Tecnologías
React, Vite, JavaScript, HTML, CSS, API de TMDB.

## Avances

| Paso | Qué hice | Para qué sirve | Commit |
|------|----------|----------------|--------|
| 1 | Creé el proyecto con Vite y la plantilla de React | Tener la estructura base y un servidor local con recarga automática | Proyecto inicial con Vite y React |
| 2 | Limpié la plantilla de Vite | Partir de una bagit se limpia, sin código que no uso | Limpia la plantilla inicial de Vite |
| 3 | Creé el componente Encabezado | Aprender a dividir la interfaz en componentes reutilizables | Crea el componente Encabezado |
